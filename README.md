# Entreno

Aplicación de rutinas de gimnasio, una serie a la vez.

## Ilustraciones

58 ilustraciones en WebP con fondo transparente se guardan en `assets/exercises/`. La función `exerciseSketchKey` asigna las imágenes a los ejercicios; las rutinas Tabata muestran una ilustración representativa del bloque.

Abre `exercise-gallery.html` para consultar la colección completa. `exercise-manifest.json` describe cada imagen y su nombre de archivo.

Las ilustraciones fueron generadas con IA en un estilo de dibujo continuo. Son imágenes rasterizadas; no constituyen un único trazado SVG verificable.

## Vista local

Desde la carpeta del proyecto, ejecuta `python -m http.server 8000` y abre `http://localhost:8000`.
